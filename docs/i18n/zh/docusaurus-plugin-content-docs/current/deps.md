# Thirdparty Dependencies & Credits

- [cinolib](https://github.com/mlivesu/cinolib.git): A generic programming header only C++ library for processing polygonal and polyhedral meshes
- [Emscripten](https://emscripten.org/): a complete compiler toolchain toWebAssembly
- [libE57Format](https://github.com/asmaloney/libE57Format): library for reading & writing the E57file format
- [Boost C++ Libraries](https://www.boost.org/): free peer-reviewed portable C++ source libraries
- [libjpeg-turbo](https://libjpeg-turbo.org/): JPEG image codec that uses SIMDinstructions
- [Blosc](https://www.blosc.org/): a blocking,shuffling and lossless compression library
- [libzip](https://libzip.org/): reading,creating,and modifying zip archives
- [Curl for People](https://github.com/libcpr/cpr): a simple wrapper around libcurl
- [Mbed TLS](https://github.com/Mbed-TLS/mbedtls): a C library that implements cryptographic primitives
- [Dear ImGui](https://github.com/ocornut/imgui): a bloat free graphical user interface library for C+4
- [miniply](https://github.com/vilya/miniply): a simple and fast parser for PLY files
- [Eigen](https://eigen.tuxfamily.org/): a C++ template library for linear algebra
- [oneTBB](https://github.com/oneapi-src/oneTBB): simplifies the work of adding parallelism to complex applications
- [FreeType](https://freetype.org/): a freely available software library to render fonts
- [Open CASCADE Technology](https://dev.opencascade.org/): full-scale 3D geometry library
- [GDCM](https://gdcm.sourceforge.net/): C++ library dedicated to reading/parsing and writing DICOMmedical files
- [OpenCTM](https://openctm.sourceforge.net/): the Open Compressed Triangle Mesh file format
- [GLAD](https://github.com/Dav1dde/glad): GL/GLES/EGL/GLX/WGL Loader-Generator based on the official specs
- [OpenVDB](https://www.openvdb.org/): efficient manipulation of sparse.time-varying,volumetric data discretized
- [GLFW](https://www.glfw.org/): library for OpenGL, OpenGL Es and Vulkan development on the desktop
- [parallel-hashmap](https://github.com/greg7mdp/parallel-hashmap): fast and memory-friendly hashmap and btree containers
- [Google](https://github.com/google/googletest) Test: C++ testing and mocking framework
- [pybind11](https://github.com/pybind/pybind11): a library that exposes C++ types inPython and vice versa
- [fmt](https://github.com/fmtlib/fmt): a library providing a fast and safe alternative to C `stdio` and C++ `iostreams`
- [spdlog](https://github.com/gabime/spdlog): very fast, header-only/compiled, C++logging library
- [Haru](https://libharu.org/): free,cross platform,open source library for generating PDF files
- [TartanLlamav/expected](https://github.com/TartanLlama/expected): implementation of `std::expected` with functional-style extensions
- [HIDAPI](https://github.com/libusb/hidapi): simple cross-platform library for communicating with HID devices
- [tiff](http://www.libtiff.org/): provides support for the Tag ImageFile Format (TIFF)
- [JsonCpp](https://github.com/open-source-parsers/jsoncpp): manipulating JSON values, including serialization and deserialization
- [TinyGLTF](https://github.com/syoyo/tinygltf): header only C++11 gITF 2.0
- [LAZperf](https://github.com/hobuinc/laz-perf): alternative LAZ implementation for C++ and lavaScript
- [tinyxml2](http://leethomason.github.io/tinyxml2/): an efficient, C++ XML parser
